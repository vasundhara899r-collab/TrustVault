# TrustVault – AI Prompts Documentation

## 1. Introduction
AI assistance was used during the development of the TrustVault Secure Document Management System to understand requirements, generate code suggestions, debug errors and improve application security.

## 2. Prompts Used

### Prompt 1: Project Structure
"Help me create a secure document management system using Python Flask and SQLite. Explain the project folder structure and required files."

### Prompt 2: User Authentication
"Write Flask login and logout functionality with admin, owner and viewer roles. Store passwords securely using password hashing."

### Prompt 3: Document Upload
"Create a document upload feature in Flask with file extension validation, secure filenames and a maximum upload size."

### Prompt 4: Document Permissions
"Implement document-level read and edit permissions. Allow document owners to grant and revoke access to other users."

### Prompt 5: Document Search
"Create a search feature to find documents by filename, owner, category and upload date."

### Prompt 6: Document Download
"Implement secure document downloading with server-side permission checks. Prevent unauthorized users from downloading private documents."

### Prompt 7: Document Editing
"Add a feature that allows authorized users to replace existing documents while preventing unauthorized editing."

### Prompt 8: Activity Logs
"Create an activity logging feature to record document uploads, downloads, edits and permission changes."

### Prompt 9: CSRF Protection
"Explain how to add CSRF protection to Flask forms using Flask-WTF and how to handle it during automated testing."

### Prompt 10: Testing and Debugging
"Help me write Python unit tests for login, document upload, permissions, downloads, editing and activity logs. Explain and fix test failures."

## 3. Benefits of AI Assistance
- Helped understand Flask and SQLite concepts.
- Improved code structure and readability.
- Helped identify and fix programming errors.
- Supported implementation of security features.
- Assisted in writing automated test cases.
- Helped prepare project documentation.

## 4. Conclusion
AI assistance supported the development and testing of TrustVault. The generated suggestions were reviewed, modified and tested during implementation. AI was used as a development aid, while the final application was tested locally.
